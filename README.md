# Хранилища данных — лабораторные работы

Номер по списку: **6**. Предметная область Data Vault: учебный график дисциплин факультета.

## Состав

- `data-vault/01_schema_and_data.sql` — документированный SQL: 3NF, Data Vault и учебные данные.
- `data-vault/02_verify.sql` — восстановление графика, сравнение моделей и пример истории изменений.
- `mongodb/01_examples.js` — все операции из методички MongoDB №1.
- `neo4j/01_lecture.cypher` — примеры лекции, адаптированные к Neo4j 5.
- `neo4j/02_social_graph.cypher` — социальный граф: 14 узлов и 36 связей.
- `neo4j/03_queries.cypher` — проверочные запросы, соседи и кратчайшие пути.
- `evidence/` — фактический вывод выполненных команд.

## Запуск

Требуется работающий Docker. На macOS с установленной Colima:

```sh
colima start
bash run.sh
```

Скрипт запускает отдельные учебные контейнеры с префиксом `lab6-` и выполняет задания.
Повторный запуск пересоздаёт только схемы `lab6_3nf`, `lab6_dv`, данные учебной MongoDB
и графы с метками `LectureDemo`, `Lab6`. Не применять эти скрипты к чужой базе данных.

| Система | Адрес | Учебная учётная запись |
|---|---|---|
| PostgreSQL | localhost:55433, БД lab6_warehouse | labuser / lab6-study-only |
| MongoDB | localhost:27018, БД lab6_mongodb | без аутентификации, только localhost |
| Neo4j Browser | http://localhost:7475/browser/ | neo4j / lab6-study-only |
| Neo4j Bolt | bolt://localhost:7688 | та же |

Пароль в примере предназначен только для этих локальных учебных контейнеров.
После просмотра можно остановить их:

```sh
docker stop lab6-postgres lab6-mongo lab6-neo4j
```

## Модели и данные

3NF содержит 5 таблиц: факультет, учебные группы, дисциплины, семестры и учебный график.
Data Vault содержит 4 Hub, 2 Link и 5 Satellite. В графике 12 записей, 2 группы,
6 дисциплин и 2 семестра. Проверка через двусторонний EXCEPT должна дать 0 расхождений.

Социальный граф описывает учебное сообщество. Персонажи вымышлены и разделены на
новичков, наставников и организаторов. Поле `photo` ссылается на локальный учебный
аватар с инициалами. Индивидуальных вариантов в заданиях MongoDB и Neo4j нет.

## Соответствие старым материалам

В MongoDB `insert` заменён на `insertOne`, оболочка `mongo` — на `mongosh`.
Удаление базы показано на отдельной `lab6_delete_demo`, чтобы сохранить остальные результаты.
В Neo4j устаревшие `START` и `HAS` заменены на `MATCH` и `IS NOT NULL`.
Для словарных запросов лекции подготовлен небольшой пример, поскольку исходный словарь не приложен.
